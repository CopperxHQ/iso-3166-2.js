## Why 249 and Not 195?

The United Nations recognizes 195 sovereign states. ISO 3166-1 includes 249 entries because it also covers:

- **Dependent territories** (e.g., Puerto Rico, Guam, French Polynesia)
- **Special areas** (e.g., Antarctica, Western Sahara)
- **Regions with distinct codes** (e.g., Hong Kong, Macau, Taiwan)
- **Uninhabited territories** (e.g., Bouvet Island, Heard & McDonald Islands)

## Use This Data Programmatically

All 249 country codes are available through `@koshmoney/countries`:

```typescript copy
import { country } from '@koshmoney/countries';

// Get all countries
const all = country.getAll();
console.log(all.length); // 249

// Look up by any format
country.getCountry('US');
// { name: 'United States', alpha2: 'US', alpha3: 'USA', numeric: '840' }

country.getCountryByAlpha3('GBR');
// { name: 'United Kingdom', alpha2: 'GB', alpha3: 'GBR', numeric: '826' }

country.getCountryByNumeric('276');
// { name: 'Germany', alpha2: 'DE', alpha3: 'DEU', numeric: '276' }
```

### Convert Between Formats

```typescript copy
import { country } from '@koshmoney/countries';

country.alpha2ToAlpha3('JP');    // 'JPN'
country.alpha3ToAlpha2('BRA');   // 'BR'
country.numericToAlpha2(840);    // 'US'
country.alpha2ToNumeric('FR');   // '250'
```

### Validate Codes

```typescript copy
import { country } from '@koshmoney/countries';

country.isAlpha2('US');     // true
country.isAlpha3('USA');    // true
country.isNumeric('840');   // true
country.isValid('XX');      // false
```

## FAQ

### Why are there 249 codes and not 195 countries?

ISO 3166-1 is not a list of sovereign states. It includes dependent territories (like Puerto Rico, Guam, Hong Kong), uninhabited territories (like Antarctica, Bouvet Island), and regions with special status (like Taiwan, Palestine). The 195 number refers to UN member states (193) plus observer states (Vatican City and Palestine).

### Are country codes case-sensitive?

By convention, alpha-2 and alpha-3 codes are uppercase (`US`, not `us`). However, many systems treat them case-insensitively. The `@koshmoney/countries` package accepts any case.

### What is the difference between alpha-2 and alpha-3?

Alpha-2 uses two letters (e.g., `US`), alpha-3 uses three (e.g., `USA`). Alpha-2 is the most commonly used format for web and APIs. Alpha-3 is used in passports and travel documents. See [Country Code Formats Explained](/blog/country-code-formats-alpha2-alpha3-numeric) for a detailed comparison.

### Do country codes ever change?

Rarely. When countries are renamed, their codes may be updated. When countries split or merge, new codes are assigned and old ones are retired. ISO maintains a list of formerly used codes.
